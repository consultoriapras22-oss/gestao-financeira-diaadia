Dúvidas frequentes

Tudo que você precisa saber

Feito para organização financeira pessoal, autônomos e MEIs com controle simples.

O pagamento é mensal?

Não. É pagamento único, com acesso vitalício e atualizações gratuitas. Você paga uma vez e usa para sempre, sem mensalidade.

Posso acessar pelo celular?

Sim. Funciona no celular, no tablet e no computador, direto pelo navegador.

Preciso instalar algum programa?

Não. Nada para instalar — é só abrir o link no navegador e usar.

Onde meus dados ficam salvos?

No próprio navegador e dispositivo (não em nuvem). Por isso é importante fazer backups regularmente.

O sistema possui backup?

Sim. Há backup automático com histórico, além de exportar e importar backup manualmente.

Posso usar em mais de um dispositivo?

Sim. Para levar seus dados de um dispositivo a outro, use a exportação/importação de backup.

O que acontece se eu limpar o navegador?

Limpar os dados do site pode apagá-los. Faça um backup antes de limpar o navegador, trocar de aparelho ou formatar o computador.

Como recebo meu acesso?

Após a compra você recebe uma chave de ativação. Ao abrir o sistema, informa a chave, cria sua senha e pronto.

O sistema serve para empresa?

É voltado principalmente para organização financeira pessoal, autônomos e MEIs. Também permite separar PF de PJ.

Como funciona o suporte?

Você conta com suporte por 90 dias após a compra, direto pelo WhatsApp.
